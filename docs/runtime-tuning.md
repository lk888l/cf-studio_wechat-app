# 遥控中央面板与运行时调参

在左右摇杆中间，面板顶部提供与「启用本地控制」相同小框样式的「运动参数调节」switch 开关。打开后显示调参，关闭后显示运行参数回显；开关下方文字同时标明当前模式。首次打开默认显示原来的控制目标、串口回传和发送信息。本地仅保存面板选择与分组，不保存或自动下发调参值。

调参分成重心标定、俯仰环、速度环、转向环、横滚环五组。通过分组下拉框选择，组内可上下滚动。每项同时提供滑块与原生数值输入框：拖动滑块立即同步输入值，输入有效值同步滑块位置。滑块按整数刻度映射到实际参数步长，支持负数和 0.001 等小数精度。输入框具有明确的宽度和输入区域，支持键盘手动修改；非负参数使用小数键盘，允许负值的参数使用可输入负号的文本键盘。

滑动和输入只修改草稿，点击该项「发送」或键盘「发送」才发送一条命令。未连接时也能编辑，连接并确认串口后才能下发；启用摇杆控制期间也可调参。输入中间态（如空字符串或单独的负号）会被保留，发送时校验完整数值；每次只更新对应参数字段，不重建整个列表。模拟模式采用同一编码和调度流程，但不调用蓝牙写入。

初始输入框是对应固件的参考默认值，并非设备回读。连接变化、模拟切换和固件档案切换会重置草稿与发送状态，避免沿用上一设备的数据。成功只显示「已发送 · 未确认执行」；不会把 GATT 写入成功当成 MCU 执行确认。参数仅作用于固件 RAM，设备重启后恢复其烧录版本的默认值。

## 可调参数

下表命令为直接发往车端的正文。main 不附换行，要求整条命令 ≤20 ASCII 字节；SoftEngine 使用 `@<正文>\n`，由现有 BLE 传输层按 20 字节分片。不会加 `nrfsend`，不会循环发送 PID 参数。

| 分组     | 参数                 | 命令正文                 | 应用范围                       | 微调步长 | 参考默认值                |
| -------- | -------------------- | ------------------------ | ------------------------------ | -------- | ------------------------- |
| 重心标定 | 最低腿高俯仰偏置 / ° | `anglebias <value>`      | −20…20                         | 0.1      | main 12.6；SoftEngine 7.0 |
| 俯仰环   | Kp                   | `anglepid -p <value>`    | 0…150                          | 0.1      | 70，默认自动模式          |
| 俯仰环   | Ki                   | `anglepid -i <value>`    | 0…1                            | 0.1      | 0                         |
| 俯仰环   | Kd                   | `anglepid -d <value>`    | −107…100                       | 0.1      | 60                        |
| 速度环   | Kp                   | `velocitypid -p <value>` | 0…10                           | 0.01     | 0.05                      |
| 速度环   | Ki                   | `velocitypid -i <value>` | main 0…9.999；SoftEngine 0…100 | 0.001    | 0.008                     |
| 速度环   | Kd                   | `velocitypid -d <value>` | 0…100                          | 0.01     | 0                         |
| 转向环   | Kp                   | `differpid -p <value>`   | −50…50                         | 0.1      | 2                         |
| 转向环   | Ki                   | `differpid -i <value>`   | 0…1                            | 0.001    | 0.001                     |
| 转向环   | Kd                   | `differpid -d <value>`   | 0…100                          | 0.1      | 0                         |
| 横滚环   | Kp                   | `rollpid -p <value>`     | −100…100                       | 0.1      | 0                         |
| 横滚环   | Ki                   | `rollpid -i <value>`     | −10…10                         | 0.1      | −0.4                      |
| 横滚环   | Kd，仅 SoftEngine    | `rollpid -d <value>`     | −100…100                       | 0.1      | 0                         |

这些是应用输入范围，不代表已验证的稳定控制范围或车端强制限幅。除以下差异外，范围与步长沿用 VOFA 配置：

- main 的速度 Ki 缩至 0…9.999，使所有可选值都能放入一次 20 字节写入。VOFA 的 0…100 范围中，`velocitypid -i 99.999` 为 21 字节，不能在旧协议下拆包。SoftEngine 保留完整范围。
- VOFA 没有横滚 Kd 控件；SoftEngine 横滚 Kd 的应用范围采用与横滚 Kp 相同的 −100…100、步长 0.1。
- 输入支持负数与小数，拒绝空值、非有限数、指数/十六进制、尾随文本、超范围及超出所列精度的值。不会静默截断精度或拼接任意命令。

main 的俯仰 Kp 会每个控制周期按腿高重算，面板标为自动计算且不允许发送；横滚 `-p` 实际误写 Ki，面板禁用 Kp，Ki 使用正确的 `rollpid -i`。main 没有横滚 Kd 接口。

当前本地 SoftEngine 支持持续手动俯仰 Kp：`anglepid -p` 同时关闭自动 Kp；俯仰组的「恢复自动 Kp」发送 `@anglepid -auto\n`。横滚 Kp、Ki、Kd 分别写入正确字段。早期 SoftEngine 版本可能没有这些新增接口，使用时应选择与实际烧录版本相符的档案。

腿高、横滚目标、速度和转向继续由双摇杆统一合并到 `R` 帧；调参面板不另发 `legheight`、`target_roll` 或 `VandD`，避免下一帧遥控覆盖独立目标。

## 调度与验证
