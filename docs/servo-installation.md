# 腿部舵机安装

顶部导航“日志”右边的“安装”是与遥控、日志并列的独立界面。

1. 连接小车蓝牙并确认串口通道，支撑车体。
2. 打开“安装”，点击“进入安装模式”。小程序先停止本地遥控发送，再发送 `install on`。
3. 等待车端确认“已锁定安装位置”。左右腿目标都是 44.5 mm，直流电机输出和自适应腿高均被屏蔽。
4. 目视确认舵机静止后安装舵盘、连杆；PWM 目标到位不能替代物理位置反馈。
5. 点击“安装完成，退出模式”。车端控制仍关闭；需要运行时，再到遥控调参页手动恢复车端控制。

安装状态以完整的车端 UART 回执为准，BLE 写入成功不等于安装成功。固件不支持、拒绝命令或 5 秒未回包时显示未确认。
蓝牙断开和切换页面不会退出车端安装模式，重新连接后点击刷新；重启小车会退出安装模式。
模拟模式下禁用真实安装操作。进入安装后的状态未确认时，本地遥控保持锁定，查询确认退出后再解锁。

协议为 `install on\n`、`install off\n`、`install status\n`（均短于 BLE 单包 20 字节）。状态示例：

```text
install: active=1 ready=1 height=44.5 control=off
```

新增安装协议与页面回归测试；2026-09-16 共 137 项 Node 测试通过，TypeScript 与微信 WXML/WXSS 编译通过。
车端已通过 ST-Link 将命令注入 UART 队列验证寄存器，尚未验证手机到 ZX-D30 的实际 BLE 传输及真机界面。
